# MSE 学习系统 Skills

专为材料科学与工程（MSE）学生设计的 AI 学习助手。

## Skills 列表

| Skill | 触发词 | 功能 |
|-------|--------|------|
| **explain-concept** | 解释、什么是、为什么 | 分层解释概念（通俗→专业） |
| **organize-notes** | 整理笔记、课后整理 | 结构化整理课堂笔记 |
| **generate-practice** | 出题、刷题、练习题 | 生成练习题 + 详细解析 |
| **study-session** | 开始学习、学习计划 | 制定学习计划，引导学习流程 |
| **exam-prep** | 考试、考前冲刺 | 快速复习 + 模拟考试 |

## 使用方法

直接在对话中说出触发词：

```
"解释一下位错"
"整理材料力学第3章笔记"
"出10道相图分析题"
"开始学习材料物理第2章"
"材料科学基础期末考试，后天考"
```

## 适用课程

材料力学 | 材料物理 | 材料科学基础 | 物理化学 | 结构材料

## 学习建议

**日常学习**：课后整理笔记 → 概念答疑 → 周末刷题

**考前准备**：
- 考前1周：系统复习（study-session）
- 考前3天：刷题训练（generate-practice）
- 考前1天：快速冲刺（exam-prep）

---

**特点**：简洁高效，符合 low-token 原则，按需展开深度。
